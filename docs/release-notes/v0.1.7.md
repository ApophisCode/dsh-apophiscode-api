# v0.1.7：动态模型目录与各型号思考档位

在 DSH 的 **设置 → ApophisCode → 插件版本** 检查更新并升级至 **0.1.7**，
包名为 `dsh-apophiscode-api`。安装后按提示重新打开原来的 DSH，核对运行版本。

- 模型完全来自当前使用中 Key 的真实目录，保留原始 ID 和返回顺序，
  不再受插件内置型号表限制；切换 Key 后自动更新列表。
- 恢复各型号自己的思考档位。优先采用接口声明，缺少时按精确 ID 读取 SDK 元数据，
  不把所有模型统一成同一套档位；Default 保留服务端默认设置。
- DeepSeek 系列对话统一使用 Responses 接口，其他系列保留各自的协议解析。
  已有明确协议来源时直接调用，避免额外验证请求阻断对话。
- 简化账户与 Key 区域，移除重复型号列表和分组、传输技术说明。
  修复切换 Key 后旧型号区域残留；余额读取失败或等待时仍可操作 Key，
  旧余额明确标注上次成功读取时间。
- 搜索型号使用当前对话 Key 的目录，图片型号使用独立图片 Key 的目录，
  保留显式选择和接口失败信息。

本机完整离线检查 **663/663** 通过，完成构建和打包；已分别验证 DeepSeek 文本调用、
工具结果回传及 Claude 文本调用。具体构建、实测范围与边界见
[验证记录](https://github.com/ApophisCode/dsh-apophiscode-api/blob/main/docs/validation.md)。

通过本地文件或开发链接安装的插件，请在 DSH 自带的 **设置 → 插件** 中显式安装
`dsh-apophiscode-api@0.1.7`。从 0.1.4 或 0.1.5 首次升级也请使用该入口。
宿主如提示发布冷却期，按提示等待后重试。
