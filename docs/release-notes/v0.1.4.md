# v0.1.4：ApophisCode 独立发行

在 DSH 插件管理器中安装或更新至 **0.1.4**，包名为 `dsh-apophiscode-api`。

- 统一 ApophisCode 的实现导出、界面组件及本地宿主兼容测试包名称。
- 提供 npm 精确版本安装、本仓库发布列表与用户主动更新入口；保留本地安装来源保护、发布冷却期及运行版本核对。
- 中英文说明包含安装、Key 设置、选模及 [Apophis 模型广场](https://www.apophis.uk/model-plaza)入口。
- 模型目录继续使用当前对话 Key 返回的原始 ID 和顺序；凭据、协议及工具边界保持独立。
- 安装包只包含当前运行文件、使用文档和完整许可；开发参考及过程记录保存在本地。

离线测试通过不代表全部型号已在真实服务通过调用。当前版本的真实 DSH 安装、跨版本更新、搜索和图片调用范围见[验证记录](https://github.com/ApophisCode/dsh-apophiscode-api/blob/main/docs/validation.md)。
