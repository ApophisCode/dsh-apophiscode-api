# v0.1.5：修复切换 Key 后模型列表未刷新

在 DSH 插件管理器中安装或更新至 **0.1.5**，包名为 `dsh-apophiscode-api`。

- 修复切换到 GPT 等其他 Key 后，「显示的模型」仍停留在之前 DeepSeek 列表的问题。
- 添加、停用、启用、移除 Key、变更 API 地址或手动刷新后，模型卡片重新读取当前目录。
- 新目录读取失败时明确显示错误；旧目录请求或勾选保存的延迟响应不会覆盖新列表。
- 保留模型原始 ID、响应顺序和已有隐藏设置；余额后续读取失败不阻止模型列表更新。
- 新增 10 个设置页回归用例，完整离线检查 **586/586** 通过。

通过 npm 安装的插件可在 **设置 → ApophisCode → 插件版本** 检查更新。
更新后重启同版本、同 profile 的 DSH，并确认运行版本为 **0.1.5**。
若宿主提示发布冷却期，请按提示等待后重试。
本地文件或开发链接来源请在插件管理器中显式安装 `dsh-apophiscode-api@0.1.5`。

本次未操作用户 DSH，也未使用用户 Key 调用真实网关；GPT Key 的实际权限与调用结果仍需现场验证。
验证范围见[验证记录](https://github.com/ApophisCode/dsh-apophiscode-api/blob/main/docs/validation.md)。
